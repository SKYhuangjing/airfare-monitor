# 航价守望 v0.5.0：桌面 UI 对齐试用说明

本版基于 `docs/ui-design/01`～`10` 的页面稿对桌面界面做视觉改造，重点是概览卡片、航程卡片、三步向导、历史价格、通知设置、系统健康、人工验证提示和首次设置。监控采集、航班解析、价格计算、调度、SQLite、邮件发送和浏览器控制均沿用 v0.4.0 的实现。

## 本轮变化

- 概览页改为四个带语义配色的指标卡、航程摘要卡与最近动态侧栏；“查看航班候选”仍读取已保存的最近完整查询。
- 航程页、候选页、历史页统一状态、含税价、筛选和操作的视觉层级。
- 航程向导提供步骤条、实时机场/日期/来源预览及分区表单；业务校验不变。
- 通知设置采用桌面与 SMTP 分区，授权码安全说明更醒目；事件类型标签仅用于说明，不是逐项设置开关。
- 所有页面的按钮、输入框、下拉、滚动条、焦点、悬停、按下和禁用状态统一样式。

## 使用与边界

解压 `AirfareMonitor-v0.5.0-UI.zip` 后，保留整个 `AirfareMonitor` 文件夹，双击其中的 `AirfareMonitor.exe`。不要只拷贝单个 EXE。它与旧版本使用同一个当前 Windows 用户数据目录，原航程、价格历史、浏览器隔离 Profile 和系统凭据不因更换程序文件夹而清除。若旧程序仍在托盘运行，请先从托盘菜单退出再打开新版本。

本轮只做离线验证：91 项自动化测试通过，打包后的 `--ui-smoke-test` 成功创建主窗口并加载 Qt 资源。未自动请求去哪儿/同程，也未发送真实测试邮件。人工验证仍必须由用户在可见浏览器中完成。
