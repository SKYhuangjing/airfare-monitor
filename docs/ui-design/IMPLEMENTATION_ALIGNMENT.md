# UI 设计稿实施对齐记录

本文件以 `docs/ui-design/01`～`10` 的 PNG 为视觉基准，同时以产品需求文档和开发手册约束交互与数据语义。设计稿中没有对应后端能力的入口不得做成假按钮。

## 当前批次：v0.5.0 桌面视觉改造（仅 UI）

### v0.5.1 日期与国内返程交互补充

- 日期输入保留键盘编辑，并增加清晰的“选日期”按钮；按钮打开较大的独立日历，点击一天即选中，无需精准命中细小下拉箭头。
- 出发日期变化后，返程日历的可选最早日期同步为去程次日。
- 国内同程航程仍仅能选择单程直达；选中两个国内机场时显示反向航程示例，提示返程需单独添加第二条航程、独立价格且占用第二个监控名额。
- 确认页也保留相同返程提醒。本轮不新增国内往返采集或组合价计算。

- `02` 概览由密集航程/动态表格改为四指标卡、航程摘要卡和动态侧栏；含税价、变化、心理价位、查询状态仍读取既有数据。
- `03` 航程管理强化容量条、卡片层级、机场三字码、来源和操作区；新增、编辑、启停、复制、删除和候选入口的回调不变。
- `04`～`06` 三步向导增加步骤条、航程实时预览和分区表单；地点、日期、来源、国内/国际能力校验与 `LegConfig` 映射不变。
- `07` 历史页统一筛选按钮、价格指标卡和曲线/记录容器；失败点仍断开价格线，不参与最低/最高统计。
- `08` 通知页将桌面事件与 SMTP 表单按设计稿分区；事件类型展示为说明标签，不新增尚未存在的逐项通知开关。邮件仅由用户主动测试。
- `09` 健康卡、浏览器设置、运行记录统一卡片样式；`01` 首次设置增加三步视觉引导；候选航班页统一指标/筛选/表格风格。
- 本批次不修改采集、解析、调度、数据库、通知策略或浏览器控制；离线 UI/单测和打包烟测可验证，真实网站与邮箱通路不在本轮自动执行。

## 已完成批次：R3 通知与异常恢复

- `08` 通知页从占位改为桌面通知开关和用户自配 SMTP 表单，测试邮件仅由用户主动发送。
- SMTP 授权码使用 Windows 系统凭据；非敏感字段存于当前用户设置文件，桌面配置不启用 CLI 的环境变量邮件入口。
- 托盘按确认低价、失败、人工处理和邮件失败通知，普通成功保持安静；应用内最近动态保留相同事件。
- `09` 系统状态新增可追溯运行记录、脱敏诊断导出，并可滚动查看健康、浏览器与报告目录信息。
- `10` 人工处理提供“打开验证页面—人工完成—重试航程”操作，临时使用同一隔离 Profile 的可见浏览器，不改持久化 headless 设置。
- 本批次只做离线/模拟验证；实际邮箱投递和真实验证页面需用户在试用中显式操作验证。

## 已完成批次：候选航班详情与同轮对比

- 概览和航程卡片均增加“查看候选”入口。
- 页面读取最近一次完整成功查询，同轮最多展示 200 条候选，不增加任何网站请求。
- 补齐航班号、机场三字码、时刻、耗时、中转、票价/税费、行李/余票及往返摘要。
- 支持搜索、直达/中转、起飞时段和心理价位筛选，以及价格、起降时间和耗时排序。
- 支持最多 3 个候选横向对比；通知、邮件和 Excel 继续使用前 10 条。
- 新查询开始写入扩展候选；旧版本历史因为只保存前 10 条，所以页面只能展示实际已有记录。

## 已完成批次：全局框架与航程管理

- 全局导航统一为“概览、我的航程、历史价格、通知设置、系统状态”。
- 侧栏使用航价守望品牌图标、产品副标题、个人工具边界和实际版本号。
- 概览标题改为按时段显示的旅行家问候，并保留真实监控状态。
- “我的航程”由紧凑表格改为两列卡片：启用状态、机场名称与 IATA、来源、单程/往返、日期、时间窗、直达/中转、心理价位、最近状态。
- 容量以“已启用 N/10”和进度条同时表达。
- 编辑、启停、复制、删除继续调用现有真实能力；复制默认暂停，删除不清理历史。

## 设计稿与真实能力的边界

| 设计稿 | 本轮处理 | 保留边界 |
| --- | --- | --- | --- |
| `02`、`03`、`07` | 对齐价格/状态层级、卡片、留白、快捷入口 | 不展示未采集的票价/历史，不伪造趋势或动态 |
| `04`～`06` | 步骤条、表单分区、预览 | 只支持既有机场与航程参数，不新增城市集合、实时地点接口或班次号输入模型 |
| `08`、`09`、`10` | 通知/健康/人工处理统一视觉 | 事件标签不是独立设置项；人工验证仍必须由用户完成 |
| `01` | 深色品牌区和首次设置视觉步骤 | 浏览器检测、偏好保存及用户数据位置沿用现有逻辑 |

## 不变约束

- 所有价格展示和提醒使用 CNY 含税总价。
- 国内自动匹配同程；国际/跨境自动匹配去哪儿。
- 每台设备最多同时启用 10 条，单浏览器严格串行，最短间隔 30 分钟。
- 不登录、不预订、不支付、不绕过验证码或设备验证。
- 不在界面假装提供尚未接通的功能。
