# v0.7.1 后台浏览器查询修复

v0.7.0 取消“显示浏览器运行过程”会启用 Chrome 无头模式。本机携程在此模式下返回 `whaleguard block`，导致国际查询等待搜索标识超时。

本版将桌面后台查询改为普通浏览器：先无窗口启动，再通过 Chrome DevTools Protocol 直接创建最小化窗口，避免先弹出再缩小。取消“系统状态 → 显示浏览器运行过程”并保存后，从下一轮生效。旧隐藏设置自动兼容；航程、历史和独立浏览器数据保留。任务栏可能仍有浏览器图标。

- 补充英文拦截页识别，及时转为需要人工处理，不将其误报为搜索超时。
- 人工检查始终打开可见的独立浏览器，保持原有后台偏好。
- 调试端口被占用、进程不匹配或浏览器不支持最小化启动时停止，不回退为弹出普通窗口。
- CLI 保留真正的 `browser.headless`；普通后台模式配置为 `headless: false`、`background: true`。

2026-10-12 经授权的携程实站验证：上海浦东—普吉 10 月 13 日去、20 日返，连续两次往返完成，均有 10 个双向直飞候选，最低含税 2,919 元；同日单程完成，2 个直飞候选，最低含税 1,471 元。三次启动与查询结束的窗口状态均为最小化，第二次启动复用相同独立 Profile。价格和组合数量会随网站更新。

本机 Chrome 154、Edge 155 均通过后台携程查询；Chrome 从后台切回可见模式后窗口正常显示。同程国内单程（上海浦东—北京首都，11 月 7 日）也在后台完成：69 个原始候选、9 个直飞候选，最低含税 ¥590。

168 项离线回归通过，覆盖旧设置、端口占用、进程归属、协议不支持、启动失败清理及人工检查；构建另做打包后 Qt 界面烟测。网站可能再次要求验证，工具只提示人工处理，不自动登录或绕过验证。
