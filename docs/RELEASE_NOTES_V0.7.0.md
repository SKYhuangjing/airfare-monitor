# 航价守望 v0.7.0

发布日期：2026-10-12。Windows 10/11 x64。

## 携程国际航价查询

- 国际、跨境和港澳台航程默认切换到携程，支持单程与官网原生往返组合。无需登录或持续下拉结果页。
- 按实际机场、去返日期、起飞时间窗、直达/中转、等待时长及舱位筛选。每个往返候选保留完整去程、返程和组合含税价。
- 成人和儿童按各自票价、税费及人数计算全体乘客 CNY 合计价；不把两个单程最低价相加，不把页面人均价直接作为多人提醒价格。
- 核对当前搜索与轮询链，只有成功响应明确报告完成才保存价格。提升往返大响应缓存容量，并提供读取失败提示。
- 查询来源可在桌面编辑器选择。省略 `provider` 或设为 `auto` 的旧国际航程会切换到携程；显式 `qunar` 保留兼容路径，其官网可用性仍取决于平台。
- 价格比较基准按平台、实际机场及去返日期隔离。旧历史保留，来源无法识别的记录不参与新平台基准。
- 补充济州机场目录，并修正小窗口中往返配置控件挤压的问题。

## 验证

- 152 项离线测试通过，覆盖解析、搜索完成条件、乘客总价、去返程规则、候选去重、二次确认、历史隔离、数据库升级、Excel 和桌面回归。
- 六项真实网站查询成功：四项国际单程、两项往返，包含多人加儿童及单程公务舱。
- 上海浦东—吉隆坡，10 月 14 日去、17 日返：1 成人允许中转时观测最低含税总价 1,903 元；2 成人加 1 儿童且双向直飞时为 5,899 元。价格为测试时观测值，后续可能变化。
- PyInstaller 与 Inno Setup 构建成功；打包程序的离线 Qt UI 烟测及资源初始化烟测均通过。核对冻结包包含携程采集和解析模块、版本 0.7.0、62 个机场及空的默认航程；烟测不查询官网或发送邮件。

详细联调记录见 [CTRIP_MIGRATION.md](CTRIP_MIGRATION.md)。更多航线、往返高端舱位、不同网络及长时间运行仍需扩大覆盖。携程行李额暂显示未知，跨机场中转暂不纳入候选。

## 下载与升级

- [安装包](https://github.com/myitheart/airfare-monitor/releases/download/v0.7.0/AirfareMonitorSetup-0.7.0.exe)

升级前从托盘退出旧版，再运行安装器。覆盖安装保留航程、历史、Excel、独立浏览器 Profile 和 Windows 凭据。默认用户数据路径为 `%LOCALAPPDATA%/AirfareMonitor/`。

安装包没有商业代码签名，Windows 可能显示“未知发布者”；从本仓库下载并核对 SHA-256。本机打包烟测不替代干净 Windows 虚拟机中的安装、覆盖升级及卸载验收。

本工具只读查询，不自动登录、预订、付款或绕过验证码及设备验证。
