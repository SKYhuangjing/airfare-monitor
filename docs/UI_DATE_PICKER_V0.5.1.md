# 航价守望 v0.5.1：日期与国内返程提示

本版只调整航程向导的输入体验，不改变 v0.5.0 的采集、调度、存储或通知逻辑。

- 出发/返程日期改为 `yyyy-MM-dd` 显示；保留键盘输入，并新增宽度至少 112 像素的“选日期”按钮。日历以独立的较大窗口显示，单击日期即完成选择。
- 返程可选日期自动从去程次日开始，减少选到无效日期的机会。
- 当前国内航班使用同程，只支持单程直达，没有国内去返程组合价查询。选中两个国内机场后，往返选项保持禁用，并在表单和确认页提示另建一条方向相反的单程航程。例如去程 `PVG → SYX`，返程需另建 `SYX → PVG`，单独选择返程日期；两条航程各占一个同时监控名额。

解压 `AirfareMonitor-v0.5.1-UI.zip`，保留整个 `AirfareMonitor` 文件夹并双击其中的 EXE。运行旧版时先从托盘菜单完全退出。更换程序文件夹不会清除当前 Windows 用户目录中的航程、价格历史、独立浏览器 Profile 或系统凭据。

验证只使用离线测试和打包 UI 烟测；未运行真实网站查询或发送测试邮件。
