# v0.7.0 携程查询超时排查

排查时间：2026-10-12。用户安装版已确认是 v0.7.0，包含携程模块。上海浦东—普吉往返，10 月 13 日去、20 日返，1 成人、经济舱、双向直飞，最近失败记录为 `IncompleteResponseError: 等待携程页面搜索标识超时`。

只读查看用户配置后确认 `browser.headless: true`。使用独立测试 Profile、相同浏览器和相同航程进行对照：

| 模式 | 页面及结果 |
|---|---|
| 隐藏浏览器 | 页面正文只有 `whaleguard block`，没有搜索标识，也没有搜索响应；v0.7.0 等待约 82 秒后超时 |
| 可见浏览器 | 页面正常初始化，最终 HTTP 200、业务状态 0、`data.context.finished == true`，906 个组合，筛选后 10 个双向直飞候选，最低含税总价 2,919 元 |

本次证据表明，隐藏模式下收到网站访问拦截页，是该环境中超时的直接原因。未观察到登录要求。没有修改用户正式配置、航程或数据库，没有发送邮件或操作预订，也没有使用任何验证绕过。

v0.7.0 的识别规则遗漏了英文拦截文本 `whaleguard block`，因而将访问拦截误报为页面搜索标识超时并重试。此前发布前六项实站验证均使用可见浏览器，隐藏模式覆盖不足。

## 现有安装版的处理方式

1. 打开“系统状态”，在“浏览器与自动查询”中勾选“显示浏览器运行过程”。
2. 保存设置，显示方式从下一轮查询生效；回到“概览”点击“立即查询”。
3. 若页面仍要求人工确认，使用应用的独立浏览器检查网站提示。工具不自动登录或绕过验证。

无需删除 Profile、航程或历史。此方法在本次独立测试环境中已成功；用户已有 Profile 的后续查询仍以实际页面结果为准。

## 源码修正

补充大小写不敏感的 `whaleguard block` 检测；将其标记为需要人工处理，及时给出隐藏模式的设置指引，不继续等待搜索标识或立即重复请求。可见模式遇到同样拦截也停止查询并要求人工检查。

以上对照记录针对 v0.7.0。独立测试摘要、截图与 Excel 位于 Git 忽略的 `outputs/ctrip-live-test/HKT-2026-10-13-1a0c-economy-return-2026-10-20/`，隐藏模式原始失败摘要位于同名 `-headless` 目录。

## v0.7.1 后台模式

旧实现将是否显示窗口映射成 `--headless`，这不只是普通窗口显示开关。具体网站拦截信号没有足够证据判断，也没有进行指纹伪装或验证绕过。

普通浏览器最小化后可以正常查询，但本机 `--start-minimized` 参数没有生效，首次窗口状态仍为 `normal`。因此最终实现使用 `--no-startup-window` 启动独立浏览器，通过本机 CDP 校验进程归属，再调用 `Target.createTarget(newWindow=true, background=true, windowState="minimized")` 直接创建最小化窗口，并在自动化连接后复核状态。只操作工具独立 Profile，不连接日常浏览器；失败停止，不回退为普通可见窗口。

桌面取消“显示浏览器运行过程”时保存 `headless: false`、`background: true`；读取旧 `headless: true` 设置时仅在桌面执行层转换，CLI 的显式无头设置仍保留。人工检查单独强制可见，不改变保存的偏好。

真实查询通过生产采集代码完成，未发送邮件：

|---|---|---|---|---|
| 普吉往返，首次启动 | true | 777 / 10 | ¥2,919 | minimized / minimized |

本机 Chrome 154.0.8037.98、Edge 155.0.4283.45。补充测试中，Chrome 从后台切回可见模式后窗口为 `normal`；Edge 后台查询同一普吉单程完成，61 个原始候选、2 个直飞候选、最低含税 ¥1,471，启动及结束窗口状态均为 `minimized`。摘要见忽略目录的 `background-compat-results.json`。

最终源码补强连接失败清理后再验证：同一最小化会话先完成携程普吉单程（61 / 2，¥1,471），再完成同程上海浦东—北京首都 11 月 7 日单程（69 / 9，¥590），均取得平台完成标志，结束仍为最小化；未发送邮件。摘要见忽略目录的 `background-final-results.json`。完整离线回归 168 项通过。

该模式仍有正常浏览器进程和最小化窗口，任务栏可能保留图标。验证结论限本机浏览器及上述航程；网站后续验证策略、其他浏览器版本和系统焦点行为仍以实际使用为准。协议不支持时提示更新 Chrome/Edge；遇到验证由用户主动打开人工检查。
